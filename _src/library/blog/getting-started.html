Getting This Show On The Road...

Publish date: 2026-04-30

I'll be honest, not really sure what I want to write here! I'm just excited to finally get this thing going. I'll just be rambling about random stuff I guess.

I've been working on a major update to this site for a little bit now and I thought I may as well start putting some content along with it, even if it's totally useless. I'm frankly terrible at web design so it's taken me far too much effort just to do what I'm sure so many other novices would have figured out much faster. Regardless, I'm having fun! At least for as long as the CSS I'm trying to write works and makes sense. It's hard, OK? I'm not using any of those fancy tools that do the under-the-hood work for you, I'm going in raw. Mostly.

I ported the site to Eleventy with this latest update because my previous method required manually updating every single page whenever I wanted to change the layout at all. Bad!. I'm still doing a ton of manual edits because it's just how I like to do things, but not at that scale, that's way too much. I could easily start using markdown if I wanted for these posts but I'm still learning how Eleventy works and I don't like the idea of a tool formatting my documents into HTML that, frankly, looks ugly as hell when you inspect the raw text. I HATE the standard writing style for HTML and CSS that you see all over the web, it's indentation galore, and it sucks ass IMO. I like having my files be super nice to read in any basic text editor, meaning few indents, and sticking to a limit of 80 characters per line. I have no idea if this is possible to configure in Eleventy, so I'm just writing the HTML manually and having the tool paste the content into the layout template I gave it. It's functionally the same as me manually copy/pasting it all, it just saves me a ton of time.

Regardless, even with Eleventy, I'm still doing a lot of basic stuff very, very poorly. I don't really care right now to be honest, I just want something that works for now and refine it later. It's literally how I've been doing it this whole time after all. If I tried getting it right first time, I'd never actually get anything released. Good enough is good enough!

Naturally, I'm still not done but I'm happy enough with what exists here for the time being. The previous version required JavaScript for the navigation menu on mobile due to CSS restrictions on how one can reference and modify other document elements. This new layout supports the checkbox trick to show/hide the menu on mobile now, so no JavaScript needed! The way it looks and works isn't exactly how I wanted, but honestly I'm not too fussed with mobile support anyway, desktop is always the main target and always will be. It works. That's all I care about right now.

In regards to the future, I have lots of loose ideas in my head as to what I want to put on this site as time marches on. The most concrete of those being devlogs for Jabbit, which I am still yet to reveal publicly. Other than that, the likely next posts will just be some random art and whatnot, and maybe the occasional ramble about things I care too much about here in the Library. I'm still working on a bunch of skills behind the scenes that I need for what is to come, as well as working on "getting my house in order" so to speak regarding real life. No details, but I'm starting a new journey of self improvement that has been long overdue. Even so, I'll try to make time for the things I was already planning on here.

Unrelated to the website and my projects, but I've been super obsessed with Re:ZERO all over again the past few days. It's honestly been years since I really went out of my way to watch anime on my own, but I'm falling in love with this story all over again after recently continuing from where season 2 left off. I remember reading ahead a good bit before season 2 existed because I just couldn't put it down. I still fondly remember the all-nighters I absolutely should not have pulled off when a friend introduced me to the show years ago. I'm shocked it's taken me this long to come back to it, but I am very much in another Re:ZERO phase once more with season 4 airing now. I'm going to pick the web novel back up again once season 4 finishes. Natsuki Subaru is one of the best MCs ever and you cannot convince me otherwise. I love him. I really want to collect all of the light novels physically one day but that's money. The web novel is free at least. Honestly insane. It's so good.

OK I go now, bye bye! :)
