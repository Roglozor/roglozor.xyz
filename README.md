# roglozor.xyz | Roglozor's Website
Source for my personal website! :D

This site uses [Eleventy](https://www.11ty.dev/) to build the static webpages
that are hosted online. You'll need to have [npm](https://www.npmjs.com/)
installed to use Eleventy.

## Prerequisites
- Have access to a terminal emulator.
- Have installed 
[npm](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm).

## Usage
1. Clone this repo with `git clone`
2. Change directory to `roglozor.xyz/`
3. Run `npm install`
4. Run `npx @11ty/eleventy --serve` to deploy a local server.
Alternately, omit the "--serve" to just build the website and handle the
server yourself.
